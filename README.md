# 🔢 NumPy Analyzer

> 🚀 A beginner-friendly Python project for performing array operations, mathematical calculations, searching, sorting, filtering, and statistical analysis using NumPy.

---

## 🌟 About The Project

**NumPy Analyzer** is an interactive, menu-driven Python project developed using the **NumPy library**.

The main purpose of this project is to provide a simple platform where users can work with numerical data and perform different operations on NumPy arrays. 📊

Instead of performing every calculation manually, NumPy allows us to perform operations efficiently on complete arrays.

This project combines multiple NumPy concepts into one application and is especially useful for students who are learning:

* 🐍 Python Programming
* 🔢 NumPy
* 📊 Data Analysis
* 📈 Statistics
* 🤖 Artificial Intelligence & Machine Learning basics

# ✨ Key Features

## 1️⃣ Create a NumPy Array

The first feature allows users to create their own NumPy array.

Users can enter:

* 📏 Number of rows
* 📐 Number of columns
* 🔢 Required elements

The entered values are then arranged according to the selected dimensions.

### 💡 Example Concept

A collection of numbers can be organized into:

**Rows × Columns**

This helps users understand the structure and shape of NumPy arrays.

---

# 2️⃣ Mathematical Operations 🧮

The project allows mathematical calculations between two arrays.

### ➕ Addition

Adds corresponding elements of two arrays.

### ➖ Subtraction

Subtracts corresponding elements of one array from another.

### ✖️ Multiplication

Multiplies corresponding elements of the arrays.

### ➗ Division

Divides corresponding elements of one array by another.

This section demonstrates how NumPy can perform calculations on multiple values at once.

---

# 3️⃣ Combine Arrays 🔗

The project provides an option to combine arrays.

Two arrays having compatible dimensions can be joined together to create a larger array.

This introduces the concept of **array stacking** in NumPy.

### 📌 Why is it useful?

Combining arrays can be useful when:

* 📊 Adding new data
* 📁 Combining datasets
* 🧮 Performing calculations on larger arrays
* 🔄 Organizing numerical information

---

# 4️⃣ Search Arrays 🔍

The search feature allows users to check whether a particular value exists in the array.

The program asks the user for a value and checks the array.

### Possible Results:

✅ **Value Found**

or

❌ **Value Not Found**

This is a simple example of searching data programmatically.

---

# 5️⃣ Sort Arrays 🔢

The sorting feature arranges the values of the array in sorted order.

Sorting is useful when working with numerical datasets because it makes values easier to analyze and understand.

### 📌 Uses of Sorting

* 🔢 Arranging numerical data
* 📊 Data analysis
* 🔍 Finding values easily
* 📈 Understanding data distribution

---

# 6️⃣ Filter Arrays 🎯

The filtering feature displays only the values that satisfy a specific condition.

For example, users can ask the program to display values **greater than a particular number**.

This demonstrates the concept of **Boolean filtering** in NumPy.

### 💡 Why Filtering is Important?

Filtering is commonly used in Data Science to select only the required information from a dataset.

---

# 7️⃣ Statistical Analysis 📊

The project also provides several statistical operations.

### ➕ Sum

Calculates the total of all values in the array.

### 📈 Mean

Calculates the average value of the array.

### 📊 Median

Finds the middle value of the dataset.

### 📉 Standard Deviation

Shows how much the values are spread around the average.

### 📐 Variance

Measures the variation of values from their average.

These concepts are very important in **Data Science and Machine Learning**.
